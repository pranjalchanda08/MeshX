Detailed Description

Header file for MeshX Non-Volatile Storage (NVS) operations.

This file provides APIs to manage the Non-Volatile Storage (NVS) used in the MeshX system. It includes functions to read, write, erase, and manage key-value pairs stored persistently.

Boot-time autonomous self-audit reconciling persisted links against baked elements.

Boot-time autonomous self-audit reconciling persisted links against baked elements.

Scans all persisted links on boot. Prunes any stale links where the local element index, variant, or functional model no longer exists in the baked composition. Increments link_epoch if any stale links are purged.
