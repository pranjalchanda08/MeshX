Detailed Description

Autonomous 1-Hop Proximity & Multi-Hop Relay Pairing Engine.

Copyright © 2024 - 2025 MeshX

Implements the 30-second pairing window state machine, RSSI threshold filtering (>= -50 dBm), multi-hop relay hop calculations, duplicate sequence suppression, and push-button/LED feedback integration hooks.

Pranjal Chanda
