Detailed Description

Autonomous Pairing Orchestration Engine interface.

Copyright © 2024 - 2025 MeshX

Handles end-to-end element pairing transactions, topology planning (1:1 unicast vs 1:N group addressing), dynamic topology promotion, and link table updates.

Initiate an autonomous pairing transaction with a peer element.

Evaluates existing topology for src_elem_idx. If an existing 1:1 link is present on func_id, initiates Dynamic Topology Promotion (MESHX_SYS_CMD_TOPOLOGY_UPGRADE) before dispatching MESHX_SYS_CMD_PAIR_REQUEST to the new peer.
