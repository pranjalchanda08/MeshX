Detailed Description

MeshX Serial Transport Layer — UART RX State Machine and Hosted Mode.

Implements the byte-level frame parser, hosted-mode GPIO bridge, and serial initialisation. Valid frames are forwarded to the MXCP single-layer dispatch via mxcp_dispatch_frame().

Frame Format (MXCP / MXSP compatible): [SOF 0xFE][LEN][TYPE][PAYLOAD...][CHK][EOF 0xEF]
