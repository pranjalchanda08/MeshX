Detailed Description

MeshX Command Protocol (MXCP) Definitions.

Unified, single-layer, table-driven command/event protocol for communication between the MeshX Engine and an external Host MCU.

Frame Format (identical structure to legacy MXSP): [SOF][LEN][TYPE][PAYLOAD][CHK][EOF]

TYPE byte encoding: Bit 7: Direction (0 = CMD Host→Engine, 1 = EVT Engine→Host) Bits 6-0: Command/Event ID
