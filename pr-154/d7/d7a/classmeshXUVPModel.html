Detailed Description

Vendor model for MeshX Unified Vendor Protocol (UVP).

This class provides a C++ wrapper for the mandatory UVP Vendor Model that must be present on every element in a MeshX device.

Send a UVP message with func_id prepended as a 2-byte LE wire prefix.

Wire layout: [ func_id (2 B, LE) | payload (N B) ]

The receiver dispatcher strips the prefix and populates ctx->func_id before invoking the element callback. See REQ-004 and meshx_uvp_dispatcher.cpp.

Parameters

type_idElement type ID (variant)
func_idFunction ID to embed at the wire payload prefix
payloadApplication payload (may be nullptr if payload_len == 0)
payload_lenApplication payload length in bytes
ack_reqWhether to request an ACK from the destination
app_idxApp key index.
Returns
MESHX_SUCCESS on success, error code otherwise

117 /* Allocate wire buffer: [func_id (2B)] + [payload (N B)] */
118 const uint16_t wire_len = static_cast<uint16_t>(sizeof(uint16_t) + payload_len);
119
120 /* Use stack buffer for common small payloads to avoid heap overhead */
121 uint8_t stack_buf[64];
122 uint8_t *wire = stack_buf;
123 if (wire_len > static_cast<uint16_t>(sizeof(stack_buf)))
124 {
125 if (MESHX_MALLOC(&wire, wire_len) != MESHX_SUCCESS || !wire)
126 {
127 return MESHX_NO_MEM;
128 }
129 }
130
131 /* Prepend func_id in little-endian byte order */
132 wire[0] = static_cast<uint8_t>(func_id & 0xFFu);
133 wire[1] = static_cast<uint8_t>((func_id >> 8u) & 0xFFu);
134
135 if (payload && payload_len > 0)
136 {
137 memcpy(wire + sizeof(uint16_t), payload, payload_len);
138 }
139
140 meshx_err_t err = send(dst_addr, type_id, wire, wire_len, ack_req, app_idx);
141
142 if (wire != stack_buf)
143 {
144 MESHX_FREE(&wire);
