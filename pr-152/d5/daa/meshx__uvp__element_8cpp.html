Detailed Description

Implementation of Unified MeshX Element for UVP.

Refactored (REQ-001) to use a composition-based logical model architecture. The monolithic if-else variant routing in element_state_change_notify has been replaced by a generic loop over logical_models that uses explicit func_id matching via can_handle() (REQ-005).
